# Сервер отчётов Му-раннера

Маленький Cloudflare Worker: игра отправляет ему события «открыл игру», «начал забег», «результат», а он пересылает их владельцу бота в Telegram. Токен бота хранится только в настройках воркера, в коде игры его нет.

## Настройка (один раз, ~10 минут)

1. **Аккаунт Cloudflare.** Зарегистрируйся на dash.cloudflare.com, бесплатного плана хватает с запасом.
2. **Создать воркер.** Workers & Pages → Create → Worker → шаблон «Hello World» → Deploy.
3. **Вставить код.** Edit code → удали всё в редакторе → вставь содержимое файла `server/worker.js` из этого репозитория → Deploy.
4. **Токен бота.** У воркера: Settings → Variables and Secrets → Add → тип **Secret**, имя `BOT_TOKEN`, значение — токен от @BotFather. Сохрани и задеплой.
5. **Адрес воркера.** Скопируй его (вида `https://moo-xxxx.ИМЯ.workers.dev`) и пришли Claude: он впишет его в игру.
6. **Свой chat_id.** Открой игру в Telegram. Бот пришлёт тебе сообщение с твоим chat_id.
7. **Последний шаг.** Добавь переменную `OWNER_CHAT_ID` (можно тип Text) с этим числом → Deploy. С этого момента все входы и результаты приходят тебе.

## Что приходит

- 👋 «зашёл в игру» — без звука уведомления
- 🏁 «прошёл уровень N»: голос или кнопки, камера, время, оставшиеся жизни — без звука
- ⚠️ ошибки доступа к микрофону — со звуком

Имя игрока берётся из подписанных данных Telegram (`initData`), подделать его нельзя. Открытия не из Telegram помечаются «❔ неизвестный».
